# Security

This project is a reference implementation and should be reviewed against your
organization's threat model before production use.

- Never commit provider credentials or customer data.
- Store secrets in an approved secret manager.
- Restrict outbound provider access and apply least-privilege IAM.
- Add authentication, authorization, rate limiting, and abuse protection at the edge.
- Define retention and deletion policies for audit records.
- Complete privacy, security, legal, and model-risk reviews for the selected provider.

To report a vulnerability, use GitHub's private vulnerability-reporting feature.
